# Calculator-C

A simple C++ command-line calculator that accepts two numbers and performs basic arithmetic operations, featuring built-in error handling for division by zero.

## Features
- **Addition (+)**
- **Subtraction (-)**
- **Multiplication (*)**
- **Division (/)** with protection against dividing by zero

## How to Run
1. Open your terminal.
2. Compile the code using a C++ compiler (like g++):
   g++ Calculator.cpp -o Calculator
3. Run the executable application:
   ./Calculator
